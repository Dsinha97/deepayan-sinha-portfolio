# docs/sources — read this first

**Two documents in this folder are factually false about Deepayan Sinha.**

`portfolio-website-plan.md` and `design-suggestions.md` are AI-generated research documents
written before the project knew anything about the person the site is for. They describe a
"Software Engineer and Systems Specialist" with projects, an award, performance figures and a
technology stack **none of which are his**. There is no Go microservices mesh, no WebAssembly
simulation kernel, no telemetry pipeline, no "Best Software and AI Project" award, and none of
the latency or throughput numbers they quote.

They are kept because their *structural* thinking — page order, metadata, security headers — was
useful, and this folder is frozen provenance: files here are never edited. They were **never** a
content source, and nothing on [deepayansinha.com](https://deepayansinha.com/) is taken from
them. What was kept, what was thrown away and why:
[docs/wiki/research-synthesis.md](../wiki/research-synthesis.md).

For what is actually true about his work, read the site, or the wiki's
[profile](../wiki/profile.md), [experience](../wiki/experience.md) and
[content guardrails](../wiki/content-guardrails.md) pages.

The other files here are accurate: `additional-cert-links.md` and `research-paper-details.md`
are link records, and `animation-plans/` are implementation plans from a design audit.
